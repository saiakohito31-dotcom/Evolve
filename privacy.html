Нууцлалын бодлого

«Evolve» вэб апп · Сүүлд шинэчилсэн: 2026-11-03

Товчоор: Нэвтрээгүй бол таны өгөгдөл зөвхөн таны төхөөрөмж дээр байна. Нэвтэрвэл төхөөрөмжүүд хооронд синк хийхийн тулд өгөгдөл Google Firebase дээр таны бүртгэлтэй холбогдон хадгалагдана. Сурталчилгаа, хяналтын (analytics) код, өгөгдөл худалдах зүйл байхгүй.

1. Энэ апп юу хийдэг вэ

Өдөр, 7 хоногийн төлөвлөгөө, дадал, тэмдэглэл, журнал, зорилгын хүснэгт хөтлөх, сэрүүлэг ба сануулга өгөх хувийн хэрэгсэл.

2. Ямар мэдээлэл хадгалагддаг вэ

Нэвтрээгүй үед. Таны бичсэн бүх зүйл (ажил, тэмдэглэл, дадал, журнал, тохиргоо) зөвхөн таны төхөөрөмжийн хөтчийн дотоод хадгалалтад (localStorage) хадгалагдана. Энэ мэдээлэл аппын эзэн рүү эсвэл өөр сервер рүү илгээгдэхгүй.

Нэвтэрсэн үед. Нэвтрэлтийг Google Firebase Authentication гүйцэтгэнэ. Үүнд дараахь мэдээлэл хадгалагдана:

  • Таны нэр, и-мэйл хаяг, профайл зураг (Google эсвэл Facebook-ээр нэвтэрсэн бол);
  • Утасны дугаар (утасны дугаараар нэвтэрсэн бол);
  • Firebase-ийн өгсөн хэрэглэгчийн дугаар (UID).

Таны төлөвлөгчийн өгөгдөл (ажил, тэмдэглэл, дадал, журнал, тохиргоо) Google Cloud Firestore дээр таны UID-тай холбогдсон нэг документ болон хадгалагдана. Аюулгүй байдлын дүрмээр (Firestore security rules) зөвхөн нэвтэрсэн тухайн хэрэглэгч өөрөө өөрийн документыг унших, бичих боломжтой.

Аппыг ажиллуулж буй хөгжүүлэгч Firebase удирдлагын самбараар техникийн хувьд бүртгэлтэй хэрэглэгчдийн жагсаалт болон хадгалагдсан өгөгдлийг харах боломжтой байдаг. Хөгжүүлэгч үүнийг хэрэглэгчийн өгөгдөл үзэхэд ашиглахгүй.

3. Гуравдагч талууд

  • Google Firebase (Authentication, Cloud Firestore) — нэвтрэлт ба cloud хадгалалт. Google-ийн нууцлалын бодлого.
  • Facebook / Meta — зөвхөн «Facebook-ээр нэвтрэх»-ийг сонгосон үед.
  • Google reCAPTCHA — зөвхөн утасны дугаараар нэвтрэх үед, хүн мөн эсэхийг шалгана. Мөн утсанд SMS код илгээгдэнэ.
  • GitHub Pages — аппын файлыг байршуулдаг. Байршуулалтын үйлчилгээ нь ердийн сервер лог (IP хаяг гэх мэт)-ийг тэмдэглэж болно.

4. Cookie, хяналт

Апп сурталчилгааны cookie, analytics, хэрэглэгчийг мөрдөх код ашигладаггүй. Нэвтрэлтийн төлөв болон таны өгөгдлийг хөтчийн дотоод хадгалалтад (localStorage, IndexedDB) хадгална — энэ нь аппыг ажиллуулахад шаардлагатай.

5. Өгөгдлөө хэрхэн устгах вэ

  • Cloud өгөгдөл + бүртгэл: Аппын «Тохиргоо» → «Бүртгэл ба синк» → «Бүртгэл болон cloud өгөгдлөө устгах». Ингэхэд Firestore дээрх таны документ болон нэвтрэх бүртгэл бүрмөсөн устна.
  • Өөр төхөөрөмж дээр: бүртгэлээ нэг төхөөрөмж дээрээс устгавал нөгөө төхөөрөмж дээрх хуулбар тэр төхөөрөмж дээр хэвээр үлдэж, нэвтрээгүй горимд шилжинэ (cloud руу дахин бичигдэхгүй). Тэр хуулбарыг дээрх аргаар өөрөө арилгана.
  • Төхөөрөмж дээрх өгөгдөл: Апп доторх «Гарах» товч энэ төхөөрөмж дээрх бүртгэлийн хуулбарыг устгана. Нэвтрээгүй үеийн өгөгдлийг хөтчийн «сайтын өгөгдлийг цэвэрлэх» эсвэл аппыг устгах замаар арилгана.
  • Facebook-ээр нэвтэрсэн бол: дээрх «Бүртгэл болон cloud өгөгдлөө устгах» нь бидэнд хадгалагдсан мэдээллийг бүрэн устгана. Мөн Facebook тохиргоо → «Аппууд ба вэб сайтууд» хэсгээс энэ аппыг хасаж болно.

Өгөгдлийн хуулбарыг «Тохиргоо» → «Нөөцлөх»-өөр .json файл болгон татаж авч болно.
